# HciController

This project was generated by the **IOsonata Eclipse Embedded CDT Managed-Project Template**.

## What you just created

- **Target MCU:** `NRF52840_XXAA`
- **MCU family key:** `nrf52`
- **BLE mode:** `disable`
- **Source language:** depends on the project type you selected in Eclipse:
  - C projects generate `src/main.c`
  - C++ projects generate `src/main.cpp`

## Project structure

- `src/main.c` or `src/main.cpp`
  - Entry point + `HardwareInit()`.
  - Peripheral blocks (UART/SPI/I2C) are generated only if you selected them in the wizard.
  - BLE code is generated only when BLE is enabled and supported by the selected MCU.
- `include/board.h`
  - **Pin map only.** Edit this file to match your board.
- `include/HciController.h`
  - Project header; includes `board.h`.

## First thing to do: set your pin map

Open **`include/board.h`** and confirm (or change) at least:

1. LEDs and buttons (if used)
2. UART pins (if UART was enabled)
3. Any SPI/I2C pins you intend to use

The generated defaults are only a starting point and may not match your exact board variant.

## Optional: oscillator configuration

If your board uses a different oscillator configuration than the default `SystemInit()`, you can define `MCU_OSC` in `include/board.h`.

Example (commented by default in `board.h`):

```c
// #define MCU_OSC { {OSC_TYPE_XTAL, 16000000, 20, 100}, {OSC_TYPE_RC, 32000, 20, 0}, false }
```

When `MCU_OSC` is defined, the generated main file declares:

```c
#ifdef MCU_OSC
McuOsc_t g_McuOsc = MCU_OSC;
#endif
```

## Build and run (Eclipse Embedded CDT)

1. Open Eclipse **Eclipse IDE for Embedded C/C++ Developers**.
2. Open the generated project.
3. **Build**:
   - `Project → Build Project`
4. **Flash / debug**:
   - Use your normal debug launch configuration for your probe (J-Link, ST-LINK, etc.).

Notes:
- The project is configured as a managed project; toolchain options are set by the wizard.
- The template expects your IOsonata workspace layout to be:
  - `${system_property:iosonata_loc}/IOsonata`
  - `${system_property:iosonata_loc}/external`

## BLE notes

- BLE generation is currently intended for **nRF52** targets.
- If BLE is enabled, the main loop is replaced by:

```c
BtAppInit(&s_BtAppCfg);
BtAppRun();
```

- Central mode includes a scan-report function with example parsing of device name and manufacturer data.
